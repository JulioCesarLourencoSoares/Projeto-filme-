**Tecnologias Utilizadas**

- Google Chrome
- Linguagem de Marcação em HTML
- GitHub

**Descrição do Projeto**
O projeto consiste no desenvolvimento de uma página web estruturada em HTML dedicada ao filme japonês de ação e aventura Kamen Rider x Super Sentai: Super Hero Taisen (2012), dirigido por Osamu Kaneda. O site busca centralizar e organizar as principais informações sobre a obra, exibindo o pôster promocional oficial, uma ficha técnica completa — que reúne dados sobre duração, classificação indicativa e país de origem — e uma sinopse detalhada sobre o conflito generalizado entre as facções dos heróis. Para enriquecer a consulta do visitante, a interface conta ainda com um link externo direto para a página oficial do filme no IMDb.
O código é uma página web estática desenvolvida em HTML5 semântico, projetada para estruturar e apresentar as informações do filme de forma clara e acessível.  Estrutura Global e Metadados: Declara o documento como HTML5 (<!DOCTYPE html>) e define o idioma da página no atributo lang. Na seção <head>, configura a codificação de caracteres UTF-8, ajusta a escala de exibição para dispositivos móveis (viewport) e define o título da aba do navegador via <title>.  Semântica e Seções (<header>, <main>, <section>): Organiza a página em blocos lógicos para melhorar a acessibilidade e o SEO. O título principal (<h1>) fica agrupado no <header>, enquanto o conteúdo principal é isolado pela tag <main> e subdividido em seções temáticas com a tag <section>.  Mídia Semântica (<figure>, <img>, <figcaption>): Agrupa a imagem do pôster e sua legenda em um contêiner <figure>, garantindo que o texto alternativo (alt) forneça acessibilidade para leitores de tela caso a imagem não carregue.  Lista de Dados (<ul>, <li>, <strong>): Utiliza uma lista não ordenada para organizar os dados da ficha técnica em pares de chave-valor (como ano, direção e duração), substituindo o uso repetitivo de tags de cabeçalho.  Navegação Externa (<a>): Incorpora um hiperlink para a página do IMDb configurado com target="_blank" para abrir em uma nova aba, acompanhado de atributos de segurança (rel="noopener noreferrer") para proteger a navegação do usuário.  .

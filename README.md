# PROJETO FILME - KAMEN RIDER X SUPER SENTAI: SUPER HERO TAISEN
**Aluno: Júlio César Lourenço Soares**

**Curso: Desenvolvimento de Sistemas/ 1IF**

**Objetivo**
- Criar um site em HTML sobre um filme de nossa escolha.

**Tecnologias Utilizadas**
- VSCode
- Google Chrome
- Linguagem de Marcação em HTML
- GitHub

**Descrição do Projeto**
O projeto consiste no desenvolvimento de uma página web estruturada em HTML dedicada ao filme japonês de ação e aventura Kamen Rider x Super Sentai: Super Hero Taisen (2012), dirigido por Osamu Kaneda. O site busca centralizar e organizar as principais informações sobre a obra, exibindo o pôster promocional oficial, uma ficha técnica completa — que reúne dados sobre duração, classificação indicativa e país de origem — e uma sinopse detalhada sobre o conflito generalizado entre as facções dos heróis. Para enriquecer a consulta do visitante, a interface conta ainda com um link externo direto para a página oficial do filme no IMDb.
O código é uma página web estática desenvolvida em HTML5 semântico, projetada para estruturar e apresentar as informações do filme de forma clara e acessível.
